# knowledge

このリポジトリは、技術メモ・学習ノート・ドキュメント集をまとめた知識ベースです。
主に開発・運用・データ基盤に関連する技術を、カテゴリごとに整理して管理しています。

## 概要

このリポジトリは、以下のような用途を想定しています。

- 各技術の基本事項を短時間で確認する
- 実務で必要なコマンドや設定を再利用する
- 学習中のメモやノートをカテゴリ別に保管する
- 技術分野ごとのインデックスから関連資料にアクセスする

Markdown ベースのドキュメントを中心に、GitHub で閲覧しやすい構成で整理されています。

## 使い方

1. トップの [index.md](index.md) からサイト全体の入口にアクセスします。
2. 技術カテゴリのインデックスから必要な分野を選びます。
3. 各ドキュメントの見出しやコード例を参照して、学習や実装に活用します。

## 特徴

- 技術ごとに分離されたページ構成
- 実務で使いやすいコマンド解説が中心
- 学習用のメモをそのまま残しやすい記録形式
- GitHub で簡単に検索・参照・更新ができる構成

## 補足

- 一部のディレクトリ名には WIP が含まれており、未完成または更新途中の資料があります。
- 主要分野は整理済みで、必要に応じて追加の技術ノートを増やしていく想定です。
- このリポジトリは個人の学習用知識ベースとして運用されています。
