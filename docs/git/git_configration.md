# Configration

## .gitconfig

```
[user]
    name = Your Name
    email = your.email@example.com

[core]
    editor = code --wait
    autocrlf = input
    eol = lf
    quotepath = false
    preloadindex = true

[i18n]
    commitEncoding = utf-8
    logOutputEncoding = utf-8

[gui]
    encoding = utf-8

[init]
    defaultBranch = main

[credential]
    helper = manager
```
